2. Repaso rápido de conceptos clave

Sesión 9 (19 oct) — APIView y Generic Views

✓APIView da control total: cada verbo HTTP se implementa como un método (get, post, etc.).
✓Las Generic Views (ListCreateAPIView, RetrieveUpdateDestroyAPIView) resuelven lo común y permiten personalizar con get_queryset().

Sesión 10 (21 oct) — CRUD completo con DRF

✓Un CRUD completo debe devolver los códigos de estado correctos: 200, 201, 204, 400, 404.
✓Los listados deben tener orden predecible y las relaciones deben mostrar información legible, no solo el ID.

Sesión 11 (22 oct) — Autenticación y permisos

✓Autenticación responde "¿quién eres?"; permisos responden "¿qué puedes hacer?".
✓JWT (SimpleJWT) se envía como Authorization: Bearer <token>.
✓IsAuthenticatedOrReadOnly permite lectura pública y escritura solo a usuarios autenticados; los permisos personalizados heredan de BasePermission.

4. Ejercicio integrador paso a paso

Vamos a dejar la API de "Biblioteca" protegida y verificada de punta a punta.

Paso 1: Autenticación JWT (repaso sesión 11)

pip install djangorestframework-simplejwt
REST_FRAMEWORK = {
    'DEFAULT_AUTHENTICATION_CLASSES': ['rest_framework_simplejwt.authentication.JWTAuthentication'],
    'DEFAULT_PERMISSION_CLASSES': ['rest_framework.permissions.IsAuthenticatedOrReadOnly'],
}
from rest_framework_simplejwt.views import TokenObtainPairView, TokenRefreshView

urlpatterns = [
    path('api/token/', TokenObtainPairView.as_view(), name='token_obtain_pair'),
    path('api/token/refresh/', TokenRefreshView.as_view(), name='token_refresh'),
]

Paso 2: Verificación end-to-end (repaso sesión 10) — sin token:

GET /biblioteca/libros/          -> 200 (lectura pública)
POST /biblioteca/libros/         -> 401 (requiere autenticación)

Con token obtenido en /api/token/:

POST /biblioteca/libros/
Authorization: Bearer <access_token>
{ "titulo": "Ficciones", "autor": 1, "precio": 42000, "disponible": true }
-> 201

Paso 3: APIView personalizado (repaso sesión 9) — agrega un endpoint de solo lectura pública que no dependa del permiso global:

from rest_framework.views import APIView
from rest_framework.response import Response
from rest_framework.permissions import AllowAny
from .models import Libro
from .serializers import LibroSerializer

class LibroDisponibleAPIView(APIView):
    permission_classes = [AllowAny]

    def get(self, request):
        libros = Libro.objects.filter(disponible=True)
        return Response(LibroSerializer(libros, many=True).data)
5. Errores comunes del bloque (repaso general)
✗Configurar IsAuthenticated global y olvidar que bloquea también los endpoints que deberían ser públicos.
✗Enviar el token sin el prefijo Bearer → 401 aunque el token sea válido.
✗Un POST con datos inválidos devuelve 500 en lugar de 400.
✗Olvidar .as_view() al conectar un APIView en urls.py.
