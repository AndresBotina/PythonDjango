Configuración de paginación y filtros sobre un listado de recursos. Adición de filtros, búsqueda y paginación a los listados del proyecto.
1. Objetivo de la sesión

Al finalizar esta sesión, el aprendiz será capaz de configurar paginación para listados grandes, agregar filtros con django-filter, y habilitar búsqueda y ordenamiento dinámico sobre los endpoints de listado.

2. ¿Por qué paginar, filtrar y buscar?

Nuestro proyecto "Biblioteca" tiene pocos registros, pero en producción un listado puede tener miles. Devolver todos los registros en una sola respuesta es lento para el servidor y para el cliente. Además, casi ningún cliente real necesita "todos los libros": necesita "los libros del autor X que contienen la palabra Y en el título, ordenados por precio".

HerramientaResuelve
PaginaciónDividir un listado grande en páginas pequeñas y manejables.
Filtros (django-filter)Permitir al cliente pedir solo los registros que cumplen ciertas condiciones exactas (ej. ?disponible=true).
Búsqueda (SearchFilter)Buscar coincidencias parciales de texto en uno o varios campos (ej. ?search=cien).
Ordenamiento (OrderingFilter)Permitir que el cliente decida el orden del listado (ej. ?ordering=precio).
3. Paginación

Ya configuramos una paginación básica global en la sesión 5. Repasemos y ajustemos en settings.py:

REST_FRAMEWORK = {
    'DEFAULT_PAGINATION_CLASS': 'rest_framework.pagination.PageNumberPagination',
    'PAGE_SIZE': 5,
}

Con esto, GET /biblioteca/libros/ devuelve como máximo 5 resultados por página, junto con enlaces next y previous:

{
    "count": 23,
    "next": "http://127.0.0.1:8000/biblioteca/libros/?page=2",
    "previous": null,
    "results": [ ... ]
}

Si se necesita un tamaño de página distinto por endpoint, se puede definir una clase de paginación propia y asignarla en el ViewSet con pagination_class.

4. Filtros con django-filter

Instalación:

pip install django-filter

Regístralo en INSTALLED_APPS y configúralo como backend de filtrado por defecto:

INSTALLED_APPS = [
    # ...
    'django_filters',
]

REST_FRAMEWORK = {
    # ...
    'DEFAULT_FILTER_BACKENDS': ['django_filters.rest_framework.DjangoFilterBackend'],
}

En el ViewSet, se indica sobre qué campos se puede filtrar:

from django_filters.rest_framework import DjangoFilterBackend
from rest_framework import viewsets, filters
from .models import Libro
from .serializers import LibroSerializer

class LibroViewSet(viewsets.ModelViewSet):
    queryset = Libro.objects.all().order_by('titulo')
    serializer_class = LibroSerializer
    filter_backends = [DjangoFilterBackend, filters.SearchFilter, filters.OrderingFilter]
    filterset_fields = ['disponible', 'autor']
    search_fields = ['titulo', 'autor__nombre']
    ordering_fields = ['precio', 'fecha_publicacion']

Con esta configuración, el cliente puede combinar libremente:

GET /biblioteca/libros/?disponible=true
GET /biblioteca/libros/?autor=1&ordering=-precio
GET /biblioteca/libros/?search=cien
5. Ejercicio práctico (para hacer en clase)
  1. Instala django-filter y configúralo como DEFAULT_FILTER_BACKENDS del proyecto.
  2. Agrega filterset_fields a un ViewSet, permitiendo filtrar por al menos dos campos exactos (por ejemplo, un booleano y una relación).
  3. Agrega search_fields incluyendo al menos un campo de texto propio y un campo de una relación (usando __).
  4. Agrega ordering_fields con al menos dos campos numéricos o de fecha.
  5. Prueba desde la Browsable API: filtra por un campo exacto, busca un texto parcial y ordena descendente por uno de los campos habilitados.
  6. Ajusta PAGE_SIZE a un valor razonable para tu proyecto y confirma que el listado incluye count, next y previous.
6. Errores comunes
✗Instalar django-filter pero registrar mal el nombre de la app en INSTALLED_APPS (es django_filters, con guion bajo, no django-filter).
✗Olvidar filter_backends a nivel de vista cuando no se configuró globalmente en settings.py → los parámetros de filtro se ignoran silenciosamente.
✗Poner en filterset_fields un campo relacionado sin verificar que acepte el tipo de filtro exacto que se espera (por ejemplo, texto libre en vez de coincidencia exacta).
✗Usar search_fields para buscar en campos numéricos esperando comparación exacta: SearchFilter hace coincidencia parcial de texto, no comparación numérica.
